# Design critique C — groups, media, music, calls, chat sheets & shared components (critic-C, 2026-11-23)

Read with `design-critique.md`. The system-wide items A1–A10 and D17–D19 are already being fixed and are not repeated here: grouped rows, switch, icon tiles, KxEmpty, 1-line subtitles, jargon, bottom padding, two-line values, chip edge fade, ripple and 48 dp. Where a problem below has the same root cause, it names the component to change.

Sources: PNGs in `app/build/screenshots-v3/` (390×844 dp) and the code in `app/src/main/java/com/kirox/app/ui/v3/**`.
