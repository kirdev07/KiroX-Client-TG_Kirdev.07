# Design critique — kiroX 1.0 (rel-test, real account), 2026-11-24 evening

Walk by the lead on the Xiaomi (1080×2400). Owner asked: «как критик по дизайну … посмотри что удобно а что нет и потом сделай все эти исправления». Fix all items; keep the v3 identity (black + soft green, glass, rounded), make it calmer and more consistent.

## A. System-wide (apply everywhere)
1. [x] **Grouped rows instead of one card per row.** Settings and its sub-screens put every row into its own rounded card with a gap → noisy «stack of pills». Group related rows into ONE rounded card with hairline dividers (inset after the icon), 8 dp between groups, section caption above (like Telegram/iOS). Applies to Settings main list, Notifications, Privacy, Data & storage, Customisation, Shield hub, kiroX functions, music settings, etc. (SetCommon/ToolKit/W6Kit/ExtraKit row helpers — one shared `KxGroup { rows }` component). — *done (design-fix): KxGroup (components/KxGroup.kt) + kxSlotShape/kxGroupItem: every groupShape() stack in SetCommon/ToolKit/W6Kit/PrivacyRules helpers renders as ONE card with hairlines inset after the icon; Settings main, Функции kiroX, Notify categories and KxCard use KxGroup directly; Shield hairlines inset.*
2. [x] **Switches**: the ON state draws a dark knob on a light-green track — reads as «disabled/inverted». Use a white (or near-white) knob on the green track when ON, grey knob on dark track when OFF, everywhere (KxSwitch and every local copy: SSwitch, TSwitch, MiniSwitch, DarkKnobSwitch, ExSwitch…). One component. — *done (design-fix): KxSwitch rewritten (48x28, near-white knob on accentDeep ON, grey knob on dark track OFF, onTint only for DND night / admin gold); SSwitch, TSwitch, TDarkSwitch, TSmallSwitch, MiniSwitch, DarkKnobSwitch, BSwitch, NgSwitch, DndSwitch, KxSwitchDot all delegate.*
3. [x] **Icon tiles colours**: Settings rows mix orange/blue/green/purple/pink/yellow tiles randomly. Use one rule: tinted tiles by group (e.g. account/security = green family, look = purple, data = blue) with the same opacity, or all neutral glass tiles with coloured glyphs. Be consistent between Settings, kiroX functions and Shield. — *done (design-fix): KxTint (security / kiroX green, look purple, data blue, help neutral); tile = glyph colour at .14 in SNavRow, KxRow, Settings, Notify, feature rows.*
4. [x] **Empty states**: mixed styles (Templates: grey text top-left; Bookmarks: centred icon circle + title + hint). Use one `KxEmpty(icon, title, hint, action?)` centred component on every list screen (templates, bookmarks, notes, reminders, hidden chats, hidden stories, scheduled, downloads, playlists, Моя музыка, calls, NotifyExceptions…), with the primary action button inside when there is one. — *done (design-fix): KxEmpty(icon, title, hint, action) in Templates (action inside), Bookmarks, Notes, Reminders, Archive, Calls, Files, Downloads, Story archive, Schedule, Hidden chats, own themes, NotifyExceptions, music (MusicEmpty), placeholders.*
5. [x] **Header subtitles**: long subtitles wrap to 2–3 lines under the title (Bookmarks «Сообщения со звёздочкой из всех чатов · только на телефоне»). Header subtitle max 1 line (ellipsis); move explanations into the screen body as a hint card or the empty state. — *done (design-fix): KxTopBar / THeader / ExHeader / MoTitleHeader subtitles 1 line + ellipsis; Bookmarks / Notes / Reminders subtitles shortened, explanation moved into the empty state.*
6. [x] **Jargon in UI text**: «punycode», «IP», «Модель … за 39 мс», «KxSendWhen»-like technical words. Replace with plain Russian («адреса-двойники и подозрительные короткие ссылки», «Обучена на 632 примерах»). Audit all v3 strings for English/technical words. — *done (design-fix): Shield subtitles and labels plain, ShieldLinks / linkWarning reasons without punycode / IP, ML Kit / модель → языковой пакет, IP → «адрес в сети», TDLib / Telegram API removed from About / Help / ads text.*
7. [x] **Bottom fixed buttons & the floating dock**: content behind the floating dock / bottom CTA must have enough bottom padding so the last row is fully readable and tappable (Settings last rows sit under the dock). Use one shared `bottomContentPadding`. — *done (design-fix): kxBottomContentPadding() = dock clearance + nav bar; default bottomPadding of Settings / Chats / Calls / Stories.*
8. [x] **Two-line values in rows**: a row title that wraps («Расшифровка и перевод» + value «на телефоне») must keep the title on one line — value moves under the title as subtitle when space is short. — *done (design-fix): KxTitleValue (value drops under the title when short) in SNavRow, W6ValueRow, RuleRow, Privacy «Кто видит», Settings rows.*
9. [x] **Horizontal chip rows** (Music «Каналы · Моя музыка · Плейлисты · Скачанные», chat list chips) cut the last chip at the screen edge with no hint — add an edge fade on the right when scrollable. — *done (design-fix): Modifier.kxEdgeFade(scroll) on the Music section chips and the chat-list folder chips.*
10. [x] **Touch feedback & sizes**: every tappable row/tile has ripple clipped to its shape, ≥48 dp height; destructive rows red only for the text+icon, not the whole card. — *done (design-fix): Kit rows ≥52 dp, ripple clipped by the group card; destructive rows = red text + icon only.*
